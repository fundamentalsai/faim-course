# Fundamentals of AI for Manufacturing (FAIM) — 4 Modules

This is a very simple **static site** that you can publish with **GitHub Pages**.

## How to use
1. Put your course logo(s) in `assets/` (optional) and update image paths in `index.html` if needed.
2. Replace the sample video `iframe` URLs with your real links in `module*.html` files.
   - If your videos are **YouTube/Vimeo**, keep the `<iframe>` structure.
   - If your videos are direct `.mp4` links, use the `<video>` example shown in each module file.
3. Update any course text in `index.html` and the module pages.
4. Commit and push to GitHub, then enable **GitHub Pages** to publish.

## Dev tips
- You can install the **Live Server** extension in VS Code to preview locally.
