Fundamentals of AI for Manufacturing

This course introduces the core ideas behind modern AI and shows how they apply to manufacturing. It blends short theory segments with hands-on walkthroughs.

Start learning

At a glance

  • 4 modules
  • Hybrid friendly — online videos + self practice
  • Final mini-project using an industry dataset
  • Prereqs: basic Python (helpful, not required)

What you'll learn

  • ANN architecture, loss functions, normalization
  • Optimizers, encoders, tokenization principles
  • Regression, time series (RNN/LSTM), image basics (CNN)
  • Working with text, basics of LLMs, intro to RAG

How it works

  • Watch the lecture videos for each module
  • Use the linked notebooks/slides to practice
  • Optionally complete a small final project
