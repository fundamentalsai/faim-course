Fundamentals of AI for Manufacturing

This course introduces the core ideas behind modern AI and shows how they apply to manufacturing. It blends short theory segments with hands‑on walkthroughs. The public can access all content freely from this site.

Start learning

At a glance

  • 4 modules (3 days each)
  • Hybrid friendly — online videos + self practice
  • Final mini‑project using an industry dataset
  • Prereqs: basic Python (helpful, not required)

What you'll learn

  • ANN architecture, loss functions, normalization
  • Optimizers, encoders, tokenization
  • Regression, time series (RNN/LSTM), image basics (CNN)
  • Working with text, basics of LLMs, intro to RAG
